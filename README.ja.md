## Overview

An adapter for Yunhu (云湖) enterprise IM — WebSocket / Webhook dual mode — built on the [ErisPulse](https://github.com/ErisPulse/ErisPulse/) architecture.

All native Yunhu events are converted to OneBot12 standard format automatically (messages, follows, group joins/leaves, button clicks, A2UI buttons, shortcut menus…). See the full event mapping table in the Chinese README below.

## Install

```bash
epsdk install YunhuAdapter
```
